# 00. Исходное задание

**Проект:** система онлайн-записи для фитнес-клубов (MVP).  

**Цель:** дать конечному клиенту возможность самостоятельно выбрать услугу, специалиста, удобные дату и время и зафиксировать запись без телефонного звонка.  

**Границы MVP:** в первой версии мы не разрабатываем административную панель для управления услугами и расписанием – все мастер-данные (услуги, специалисты, доступные слоты) предварительно загружаются в базу данных техническими средствами. Сервис аутентификации и авторизации считается внешним, мы получаем от него идентификатор пользователя.

**Каталог услуг.** Типы занятий: групповые (йога, зумба, сайклинг) и персональные тренировки. У групповых занятий есть ограничение по вместимости (максимальное количество участников). У персональных тренировок вместимость = 1. Длительность занятия фиксирована (обычно 45, 60 или 90 минут).

**Ресурс – тренер.** Для группового занятия указывается тренер, для персонального – тренер привязывается к записи. Расписание групповых занятий формируется заранее (например, «Йога с Ивановым, понедельник 19:00–20:00, зал 1, макс. 25 мест»). Персональные тренировки – слоты тренера, которые клиент может занять.

**Особые поля записи.** Для групповых занятий запись осуществляется на конкретный сеанс. Счётчик занятых мест уменьшается при записи. Важно исключить повторную запись на один и тот же сеанс.

**Ограничения.** Запись на групповое занятие закрывается, когда количество записавшихся достигает лимита. При отмене записи место освобождается. Персональная тренировка проверяет занятость тренера на указанный интервал.
